## 1. 核心原则：事件分辨率决定"拟合"分辨率

新分布记录（事件）只到**省级** ⇒ 危险率模型**只能在省级拟合**。
市/县/网格**不应假装有细尺度事件去重新拟合**，而是：

```
省级（事件所在）→ 拟合 M4 ──► 取系数(β₀,β_clim,β_eff,β_int)+随机效应
                                 │
   细单元继承省级 SDM 候选         ▼
   + 降尺度气候/努力 ───────► plug-in 预测（不产生新事件，只产生 hazard 面）
```

## 2. 各要素分层处理（推荐）

| 要素 | 省级（拟合层） | 市/县（plug-in，**有效，已实现**） | 50/100km 网格（**当前阻塞**） |
|---|---|---|---|
| **风险集** | species×province×year，唯一拟合用 | 继承省级候选→映射到单元，**仅用于在哪些单元出图**，无新事件 | 同左（理论上） |
| **气候** | temp_grad_z（省×年时变，头条） | **省级广播**（气候在省内近似均匀；本机无栅格做不出单元时变气候） | 需单元×年时变气候=**需原始栅格**，本机无 → 阻塞 |
| **努力** | log_effort_visits_z（省级聚合尺度） | **单元原生**（`unit_effort_prefecture/county.csv`，单元内标准化，保留相对差异） | 社区网格努力**2024 仅 64/941 格有数据**(93% 空白)；且与省级聚合尺度不兼容 → 阻塞 |
| **预测** | 省级 hazard（已出 Fig 5） | plug-in：`table_{prefecture,county}_future_mapped_from_province.csv`（已存在，code 43） | — |

> **关键技术点（努力尺度兼容性）**：省级模型的 effort 是"省级聚合量"尺度；网格是"单格计数"尺度。
> 若把网格努力**按省级口径重标准化**，所有格都被判成"低努力"(实测 eff_z∈[−2.0,−1.0])，
> 因 temp_grad 主效应为负（−0.131），未来 hazard 反而坍塌到 ~0 —— 这是**尺度错配伪迹**，不可用。
> 市/县之所以可行，是因为 `unit_effort_*` 在**单元层内**标准化、保留相对高低（北京市 z≈3.3），
> 给出可信的**相对**hazard 面。

## 3. 生态网格阻塞的具体证据（本机实测）

2. **气候网格 vs 努力网格编号不兼容**：气候网格 `grid_id` 54–3665(n=1739)，努力网格 1–941(n=941)，

3. **网格唯一可得的原生气候=`mahalanobis_dist`**，但其**省级主效应为负**且前推 hazard 反降；
   `climate_velocity` 省级**无交互**(HR=0.93, p=0.21) ⇒ 无合适的网格原生气候轴。
4. **50km 双重缺失**：50km 面板既无 `mahalanobis`、也无经纬度坐标 ⇒ 既不能算指标也不能成图。
